# Burger Studio - Catálogo Digital con Carrito

Burger Studio es una página web para un emprendimiento local de comida rápida. El proyecto permite mostrar productos por categorías, agregar productos a un carrito y generar un pedido listo para enviar por WhatsApp.

## Objetivo del proyecto

Crear un catálogo digital para un negocio local, sin pasarela de pago, donde el cliente pueda revisar productos, elegir lo que desea comprar y enviar su pedido mediante WhatsApp.

## Funciones principales

- Catálogo visual de productos.
- Filtros por categorías.
- Carrito de compras interactivo.
- Suma automática del total estimado.
- Botones para aumentar, disminuir o eliminar productos del carrito.
- Generación automática de mensaje para WhatsApp.
- Opción de retiro en local o entrega a domicilio.
- Campos para datos del cliente en caso de domicilio.
- Campo de observaciones del pedido.
- Diseño responsive adaptable a computadoras, tablets y celulares.

## Cómo funciona

1. El usuario navega por el catálogo.
2. Selecciona productos usando el botón de agregar.
3. Los productos se muestran dentro del carrito.
4. El sistema calcula el total automáticamente.
5. El usuario elige retiro en local o domicilio.
6. Al confirmar, se genera un mensaje con el pedido para WhatsApp.
